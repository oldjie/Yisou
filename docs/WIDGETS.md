# 自用版桌面小组件

0.8.3-personal.2 只提供4×1组件：左侧搜索框，右侧豆瓣、淘宝、闲鱼、微信、拼多多五个等宽图标。没有翻页箭头、滚动列表或页码，缩放时五项均完整显示。

点图标打开对应应用的快捷输入窗，点搜索框可先输入再选择应用。搜索跳转、微信校准、历史开关和深浅外观沿用0.8.3。长按首页任一应用图标可调整排序，组件同步采用相同顺序。

通过一搜设置中的“添加桌面小组件”或系统桌面添加4×1小工具。覆盖安装后组件应自动刷新；桌面仍显示旧缓存时可移除后重新添加。

组件用标准RemoteViews固定按钮实现，Android8及以上使用同一布局，不再需要集合适配服务，所有跳转使用不可变PendingIntent。组件不展示关键词历史。
